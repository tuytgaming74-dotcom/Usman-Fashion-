# Usman Fashion Website

## Included
- Responsive one-page fashion website
- Home, Products, About and Contact sections
- WhatsApp order buttons linked to 0332 4679639
- Lahore shop address
- Mobile-friendly layout
- Basic SEO title and description

## How to put it online
1. Buy a domain such as usmanfashion.pk or usmanfashion.com.
2. Buy web hosting.
3. Upload `index.html` and `style.css` to the hosting public folder (often called `public_html`).
4. Open the domain in your browser.
5. For Google Search, verify the domain in Google Search Console and submit the sitemap when one is added.

## Before publishing
Replace the sample product prices/names with your real products and add real product photos. The current product blocks use simple placeholder backgrounds so the site works immediately without external image dependencies.
